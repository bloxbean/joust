@julclang/state-client

Experimental

The npm path runs JOUST’s toolchain and runtime as WebAssembly built with GraalVM Web Image, which is itself experimental. Java with Gradle and cardano-client-lib is the supported, first-class path: see Quick start: Java.

@julclang/state-client is the JavaScript client for JOUST contracts: it encodes calls from a contract’s description, verifies prepared transactions before a CIP-30 wallet signs them, and reads the chain. It has no engine and no Wasm, so it is what a page bundles. Ledger formats go through cardano-js-sdk (@cardano-sdk/core 0.47.1, pinned exactly); Plutus data through its own model and CBOR (pdata.js). Source: js/state-client/src/index.js, types in src/index.d.ts.

Entry point Contents
@julclang/state-client everything below, unless marked otherwise
@julclang/state-client/devwallet devWallet, deriveAccount, DEVKIT_MNEMONIC
@julclang/state-client/codegen generate
@julclang/state-client/ledger the cardano-js-sdk adapter (ledger helpers)
@julclang/state-client/pdata Plutus data: Data, decodeData, encodeData, dataHex, dataEqual, CborError
bin joust-gen generates typed clients from descriptions

Functions that once took cardano-serialization-lib (CSL) as their first argument still accept it, and ignore it.
