JOUST dApp

Java state contracts, called from the browser with a CIP-30 wallet. Every transaction is verified in this page before the wallet signs it.

No wallet connected

Counter

Anyone can increment; only its owner can reset or close it (and gets the deposit back).

Bank

A bank instance with accounts as owned objects: each account is its own UTxO, so customers never contend.

Activity

With the switch on, the service's transactions are tampered with before they reach the page: an output to an attacker, a redirected collateral return, another call, a certificate. The page's verifier must refuse each one; the wallet is never asked to sign.
