<Aside type="caution" title="Deprecated">
`.jsc` v1 ([ADR-0005](https://github.com/bloxbean/joust/blob/main/docs/adr/0005-option-e-jsc-dsl.md)) is frozen, not
removed: a v1 file (one that does not start with `jsc 2`) still builds, unchanged, so a script deployed from it stays
rebuildable, and every build warns `JSC9006`. Write new contracts in [.jsc 2](/languages/jsc/), and translate a v1 file
with [`joust migrate`](/languages/jsc-migration/) (a migrated contract is a new script).
</Aside>

This page defines v1 as the frozen front end implements it
([`Lexer.java`](https://github.com/bloxbean/joust/blob/main/julc-state-dsl/src/main/java/org/julclang/state/dsl/Lexer.java),
[`Parser.java`](https://github.com/bloxbean/joust/blob/main/julc-state-dsl/src/main/java/org/julclang/state/dsl/Parser.java),
[`Lowering.java`](https://github.com/bloxbean/joust/blob/main/julc-state-dsl/src/main/java/org/julclang/state/dsl/Lowering.java)).
`examples/dsl`'s `Jar.jsc`, `Points.jsc` and `Guards.jsc` are v1 files.

v1 is imperative: state fields are assigned (`total += received`, `points[to] += n`), and each assignment becomes a
fresh local in the generated Java (single static assignment). An `if` arm becomes a static helper that runs only when
taken and returns the fields it assigns.

## Grammar at a glance

```text
file        = "package" name { "." name } [";"]
              "contract" Ident [ "(" option { "," option } ")" ] "{" { member } "}"
option      = ( "minAda" | "maxDatumBytes" | "maxValidityMs" ) "=" Int
member      = "state" Ident ":" type [";"]
            | "init" params { modifier } block
            | ( "action" | "destroy" ) Ident params { modifier } block
            | "view" Ident params ":" type "=" expr [";"]
params      = "(" [ Ident ":" type { "," Ident ":" type } ] ")"
type        = "Int" | "Bool" | "Bytes" | "Key" | "Map" "<" "Key" "," "Int" ">"
modifier    = "payable" | "open" | "batched" [ "only" ] | ( "only" | "after" | "before" ) Ident
block       = "{" { stmt [";"] } "}"
stmt        = "let" Ident "=" expr
            | "require" expr String
            | "pay" expr "to" expr
            | "if" expr block [ "else" ( "if" ... | block ) ]
            | "delete" Ident "[" expr "]"
            | [ "this" "." ] Ident ( "=" | "+=" | "-=" ) expr
            | Ident "[" expr "]" ( "=" | "+=" | "-=" ) expr
expr        = binary operators by precedence, then unary "!" | "-", then primary
primary     = Int [ "ada" ] | Hex | "true" | "false" | "this" "." Ident
            | Ident "(" [ expr { "," expr } ] ")" | Ident "[" expr "]" | Ident | "(" expr ")"
```

A file holds exactly one contract (`one contract per file`). Members can come in any order; state fields keep their
order in the state record.


## Lexical rules

| Element | Rule |
|---|---|
| Whitespace | Spaces, tabs and newlines separate tokens; newlines are not significant |
| Comments | `//` to the end of the line. There are no block comments |
| Identifiers | A letter or `_`, then letters, digits or `_`. Case-sensitive |
| Integers | Decimal digits; `_` may separate groups (`1_000_000`). No sign: `-5` is unary minus applied to `5` |
| `ada` suffix | `5 ada` is `5000000` (multiplied by 1,000,000). Only directly after an integer literal |
| Bytes | `#` then hex digits (`#cafe`), an even number of them; upper case is accepted and lower-cased. `#` with 56 digits (28 bytes) is a `Key`, any other length is `Bytes` |
| Strings | `"..."` on one line, no escapes. Used only as `require` messages |
| Separators | `;` is optional after a statement, a state field, a view and the package line |
| Symbols | `+= -= == != <= >= && \|\| { } ( ) [ ] , : ; = < > + - * / % ! .` |


## Contract options

`contract Name(option = value, ...)`. Values are integer literals. Each becomes the `@StateContract` element of the
same name ([Annotations](/reference/annotations/)).

| Option | Java element | Default | Meaning |
|---|---|---|---|
| `minAda` | `long minAda()` | `0` (derived: `4310 * (160 + 200 + maxDatumBytes)`, rounded up to 0.1 ADA) | Lovelace locked as the state UTxO's min-ADA deposit. A value below the derived one is a compile error |
| `maxDatumBytes` | `int maxDatumBytes()` | `512` | Largest serialised state the validator accepts |
| `maxValidityMs` | `long maxValidityMs()` | `3600000` | Widest validity interval (`validTo - validFrom`, POSIX ms) for a call that reads `Ctx` |

Any other name is an error: `unknown option 'x' (minAda, maxDatumBytes, maxValidityMs)`.


## Types

| `.jsc` | Java | Values | Where allowed |
|---|---|---|---|
| `Int` | `BigInteger` | Arbitrary-precision integers | Fields, parameters, lets, view results |
| `Bool` | `boolean` | `true`, `false` | Fields, parameters, lets, view results |
| `Bytes` | `byte[]` | Byte strings | Fields, parameters, lets, view results |
| `Key` | `byte[]` | A 28-byte key hash | Fields, parameters, lets, view results |
| `Map<Key, Int>` | `MerkleMap` | Keys to non-negative `Int`s; absent reads as 0 | **State fields only** |

Assignability: every type accepts itself, and `Bytes` also accepts a `Key`. `Key` does not accept `Bytes`. `==` and
`!=` accept `Bytes` and `Key` in either order. Any other map type is an error: `v1 maps are Map<Key, Int>`.

Every `Key` parameter of an `init`, `action` or `destroy` gets a generated first check,
`Require.that(ByteStringLib.length(p) == 28, "File.jsc:L: p must be a 28-byte key hash")`.


## Members

| Member | Syntax | Generated Java | Rules |
|---|---|---|---|
| State field | `state name: Type` | A component of `public record State(...)`, in order | At least one; names unique |
| Init | `init(params) modifiers { body }` | `@Init public static State init(params[, Ctx ctx])` | Exactly one; no name; cannot pay |
| Action | `action name(params) modifiers { body }` | `@Action public static State name(State s__, params[, Ctx ctx])`, or `Outcome` when the body pays | |
| Destroy | `destroy name(params) modifiers { body }` | `@Destroy public static JulcList<Payout> name(State s__, params, Ctx ctx)` | Cannot assign state; cannot be `payable`; must pay out the whole balance |
| View | `view name(params): Type = expr` | `@View public static T name(State s__, params)` | Cannot return a `Map`; cannot read `caller`, `received`, `balance`, `validFrom`, `validTo` or time |

Method names are unique across the contract (no overloading). When any method pays, the class also gets
`public record Outcome(State state, JulcList<Payout> payouts) {}`.

**When a method takes `Ctx ctx`:** always for a `destroy`; when it is `payable` or `batched`; when its body mentions
`caller`, `received`, `balance`, `validFrom`, `validTo`, `after(...)` or `before(...)`.

**Init defaults:** `Int` fields start at `0`, `Bool` at `false`, `Map` at `MerkleMaps.empty()`. `Bytes` and `Key`
fields have no default and must be assigned on every path.


## Modifiers

Written after the parameter list, in any order, each at most once.

| Modifier | Annotation | Allowed on | Field type | Rules |
|---|---|---|---|---|
| `payable` | `@Payable` | `init`, `action` | | Not on a `destroy` |
| `only f` | `@SignedBy("f")` | `action`, `destroy` | `Key` | Not on `init`; not with `batched`; not with `open` |
| `after f` | `@ValidAfter("f")` | `action`, `destroy` | `Int` | Not on `init`; not with `batched` |
| `before f` | `@ValidBefore("f")` | `action`, `destroy` | `Int` | Not on `init`; not with `batched` |
| `batched` | `@Batched` | `action` | | Not in a contract with a `Map` field |
| `batched only` | `@Batched(only = true)` | `action` | | Intent-only. `batched only owner` parses as `batched` plus `only owner` |
| `open` | (none) | `action`, `destroy` | | Says that anyone may call a method that pays out; contradicts `only` |

**Audience rule:** an `action` or `destroy` that pays (any `destroy`, or any method with a `pay`) must have
`only <key field>` or `open`.


## Statements

| Statement | Meaning | Lowering | Rules |
|---|---|---|---|
| `let x = e` | Binds an immutable local, visible to the end of its block | `T x__1 = e;` | Must be used; not a `Map`; name not already a let, parameter or field |
| `f = e` | Assigns a state field | A fresh local `f__k` | Types must match; not in a `destroy` |
| `f += e`, `f -= e` | Adds to / subtracts from an `Int` field | `f.add(e)`, `f.subtract(e)` | `Int` field and value; the field must have a value |
| `this.f = e` (also `+=`, `-=`) | Assigns field `f` when a parameter has its name | As above | |
| `m[k] = v`, `m[k] += v`, `m[k] -= v` | Writes a map entry | `MerkleMaps.putInt`, or `MerkleMaps.remove` when the new value is 0 | `k` is a `Key`, `v` an `Int`; the new value must be ≥ 0 (checked at run time) |
| `delete m[k]` | Removes a map entry | `MerkleMaps.remove(m, k)` | `k` is a `Key` |
| `require cond "msg"` | Fails the call unless `cond` holds | `Require.that(cond, "msg")` | `cond` is a `Bool`; the message is required |
| `pay amount to key` | Adds a payout of `amount` lovelace | `Payouts.add(payouts, key, amount)` | `amount` is an `Int` ≥ 0 (checked at run time; 0 is skipped), `key` a `Key`; not in `init` |
| `if c { ... } else { ... }` | Branches; `else if` chains | One static helper per arm (`m__ifK_then`, `m__ifK_else`) and a record `IfArmK` of the fields it assigns | `c` is a `Bool`; only the taken arm runs |

Assignments, map writes and `delete` are state writes: a `destroy` cannot contain them. Parameters, lets and
built-ins are read-only. There are no loops and no `return`.


## Expressions

### Operators and precedence

Lowest precedence first. Binary operators are left-associative; comparisons do not chain (`a < b < c` is an error).

| Level | Operators | Operands | Result | Java |
|---|---|---|---|---|
| 1 | `\|\|` | `Bool` | `Bool` | `a \|\| b` (short-circuit: the right side runs only when the left is false) |
| 2 | `&&` | `Bool` | `Bool` | `a && b` (short-circuit) |
| 3 | `==` `!=` | Same type (`Bytes` and `Key` mix) | `Bool` | `Int`: `compareTo(...) == 0`; `Bool`: `==`; `Bytes`/`Key`: `ByteStringLib.equals`. Not on maps |
| 4 | `<` `<=` `>` `>=` | `Int` | `Bool` | `a.compareTo(b) < 0`, ... |
| 5 | `+` `-` | `Int` | `Int` | `add`, `subtract` |
| 6 | `*` `/` `%` | `Int` | `Int` | `multiply`, `divide` (truncates toward zero, `QuotientInteger` on chain), `remainder` (sign of the dividend, `RemainderInteger` on chain) |
| 7 | unary `!`, unary `-` | `Bool`, `Int` | same | `!(a)`, `a.negate()` |

Division by zero fails on both sides. Parentheses group as usual.

### Primary expressions

| Form | Type | Java |
|---|---|---|
| `42`, `1_000`, `2 ada` | `Int` | `BigInteger.valueOf(...)`; a literal must fit in 63 bits |
| `true`, `false` | `Bool` | `true`, `false` |
| `#cafe` | `Bytes` (`Key` when 28 bytes) | `new byte[]{...}` |
| `name` | The let's, parameter's or field's type, or a built-in's | See the resolution order below |
| `this.f` | The field's type | The field's current value |
| `m[k]` | `Int` | `MerkleMaps.getInt(m, k, BigInteger.ZERO)` |
| `fn(args)` | See functions | |
| `(e)` | The type of `e` | |

**Name resolution:** a bare name is a `let`, else a parameter, else a state field, else a built-in, else an error
(`unknown name 'x'`). A field read before it has a value is an error; a `Map` field must be indexed (`m[k]`), not
read whole.

### Built-in values

| Name | Type | Java | Meaning |
|---|---|---|---|
| `caller` | `Key` | `ctx.caller()` | The verified signer of the call (in a batch: the intent's owner) |
| `received` | `Int` | `ctx.received()` | Lovelace the call adds (in a batch: what the intent carries) |
| `balance` | `Int` | `ctx.balance()` | Lovelace the instance holds, min-ADA deposit included (in a batch: at that point of the fold) |
| `validFrom` | `Int` | `ctx.validFrom()` | Lower bound of the transaction's validity interval (POSIX ms) |
| `validTo` | `Int` | `ctx.validTo()` | Upper bound of the validity interval (POSIX ms) |

### Functions

| Function | Arguments | Result | Java | Rules |
|---|---|---|---|---|
| `min(a, b)` | `Int`, `Int` | `Int` | `(a.compareTo(b) <= 0 ? a : b)` | |
| `max(a, b)` | `Int`, `Int` | `Int` | `(a.compareTo(b) >= 0 ? a : b)` | |
| `has(m, k)` | Map field, `Key` | `Bool` | `MerkleMaps.contains(m, k)` | The first argument is a bare map field name |
| `isEmpty(m)` | Map field | `Bool` | `MerkleMaps.isEmpty(m)` | The first argument is a bare map field name |
| `after(t)` | `Int` | `Bool` | `Clock.after(ctx, t)` | Only as a requirement: at the top of a `require` or a conjunct under `&&` |
| `before(t)` | `Int` | `Bool` | `Clock.before(ctx, t)` | Only as a requirement, as `after` |

`after(t)` holds when the whole validity window is after `t`, so `!after(t)` does not mean "before `t`". That is why
it cannot be negated, used under `||`, or used as an `if` condition.


## What the lowering generates

| `.jsc` | Generated Java |
|---|---|
| The file | `package p; ... @StateContract(options) public class Name { ... }` at `p/Name.java`, with the header comment `GENERATED from File.jsc by julc-state-dsl (ADR-0005). Do not edit: change the .jsc file.` |
| Each method and statement | A `// File.jsc:line` comment above it |
| Current state | The parameter `State s__`; fields read as `s__.f()` |
| An assignment | A fresh local (`total__1`, `total__2`, ...) |
| An `if` | `boolean cond__k = ...;` then `cond ? m__ifK_then(...) : m__ifK_else(...)`; each helper takes every value live at the `if` (parameters, lets as `x__in`, fields as `f__in`, `payouts__in`, `ctx`) |
| An arm that assigns nothing | Returns `true`; the call is wrapped in `Require.that(..., "File.jsc:L: unreachable")`, so its checks run |
| An arm that assigns | `record IfArmK(...)` of the assigned fields (and `payouts`); the call site reads them back |
| A `pay` | `Payouts.add` on a threaded `JulcList<Payout>`, starting from `Payouts.none()` |
| A map write | `MerkleMaps.getInt` / `putInt` / `remove`, with a non-negative check |

The runtime checks the lowering adds, with their messages:

| Check | Message |
|---|---|
| A `Key` parameter is 28 bytes | `File.jsc:L: p must be a 28-byte key hash` |
| A map entry stays ≥ 0 | `File.jsc:L: m entries cannot go negative` |
| A payout is ≥ 0 | `File.jsc:L: a payout cannot be negative` |

## Errors

v1 errors print as `file:line:col: error: message`, without a code; the only warning is a destroy that never reads
`balance`. The checker applies the processor's rules (modifier legality, field types, views without `Ctx`) at `.jsc`
positions. Every v1 build also prints `JSC9006`, the deprecation warning.
