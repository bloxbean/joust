The public API of `julc-state-runtime` (package `org.julclang.state.runtime`) and `julc-state-server` (package
`org.julclang.state.server`), from the sources in
[`julc-state-runtime/src/main/java`](https://github.com/bloxbean/joust/tree/main/julc-state-runtime/src/main/java/org/julclang/state/runtime).
For how to use them, see [Java off-chain runtime](/apps/java-runtime/).

Most applications use only the generated `<Name>Client`, `StateRuntime`, `Compose`, `WalletAccount`, `PreparedTx`
and the exceptions. The rest is what generated clients, the testkit and the JavaScript engines are built on; it is
public so that they can reach it, and it is marked **internal** below where you should not need it.

<Aside type="caution">

JOUST is pre-release. These signatures can change before the first release.

</Aside>

## Generated client: `<Name>Client`

Generated by the processor into the contract's package. Shown for a contract `Name` with state `S`.

| Member | Kind | Description |
|---|---|---|
| `SPEC` | `static final ContractSpec<S>` | The contract's spec: name, validator class, state class, min-ADA, `maxDatumBytes`, `maxValidityMs` |
| `contract(StateRuntime runtime [, P params])` | static | The `StateContractHandle<S>` on that network (with `@Params`: for that parameter set) |
| `policyIdFor(P params)` | static | With `@Params` only: the policy id of that parameter set |
| `deploy(StateRuntime runtime, [P params,] Account callerAccount, args... [, BigInteger payLovelace] [, Value payAssets])` | static | Runs `@Init`, creates an instance, returns a client for it |
| `at(StateRuntime runtime, [P params,] String instanceId)` | static | Reconnects to an existing instance |
| `<action>(Account callerAccount, args... [, payLovelace] [, payAssets] [, Account... cosigners or Authorization authorization])` | instance | Runs an `@Action` or `@Destroy`; returns `CallResult<S>` |
| `<view>(args...)` | instance | Runs a `@View` on the current state, off chain |
| `state()` | instance | `S`: the current state |
| `lovelace()` | instance | `BigInteger`: lovelace held, deposit included |
| `fullValue()` | instance | `org.julclang.ledger.Value`: everything held |
| `instanceId()` | instance | `String`: the instance id (hex thread-token name) |
| `instance()` | instance | The underlying `StateInstance<S>` |

Contracts with owned objects also get, per owned type, a creation method returning a typed object wrapper
(for example `BankClient.open(Account, BigInteger)` returning `AccountObject` with `objectId()`, `value()`,
`lovelace()`, `fullValue()` and the owned actions), an accessor by id (`account(String objectId)`) and a
`<TYPE>_CODEC`. Contracts with `@Batched` actions also get `INTENTS` (an `IntentCodec<S>`), `<action>Intent(...)`
methods returning `IntentHandle<S>`, `batch(Account, int)`, `pendingIntents()` and `intent(String)`.
Contracts with keyed types (ADR-0016) get, per keyed type `T`, `<t>List()`, `<t>(byte[] key)`, `<t>Exists(byte[] key)`,
`<t>Keys()`, one insert method per `@OwnedInit`, a `<T>Object` wrapper and a `<T>_TYPE` constant: see
[Keyed objects](#keyed-objects).

### StateRuntime.Builder

| Method | Default | Description |
|---|---|---|
| `chainTime(ChainTime)` | **required** | Slot and POSIX time conversion and the tip; `build()` fails without it |
| `network(Network)` | `Networks.testnet()` | |
| `evaluator(TransactionEvaluator)` | none | Script budget evaluation, e.g. JuLC's `JulcTransactionEvaluator` |
| `ttl(Duration)` | 10 minutes | Validity window of calls that read `Ctx` or time annotations, clamped to the contract's `maxValidityMs`. Must stay inside the network's time horizon |
| `maxRetries(int)` | 3 | Rebuilds after the node rejected a call because the state moved |
| `confirmTimeout(Duration)` | 90 seconds | Wait for a submitted transaction to appear on chain |
| `address(byte[] pkh, String bech32)` | none | Pay this key hash at this address instead of its enterprise address |
| `log(Consumer<String>)` | no-op | Progress messages |
| `onBuilt(Consumer<BuiltTx>)` | none | Called with every transaction built, before it is submitted or returned |
| `referenceScript(Utxo)` | none | A known reference-script output; contracts with that script hash use it instead of scanning their address |
| `mapStore(NodeStore)` | RocksDB | Node store for MerkleMap mirrors |
| `mapStorePath(String)` | `joust.mapStore` system property, else `./.joust/mpf` | Directory of the default RocksDB store. The property value `memory` keeps it in memory (tests) |
| `mapProver(MerkleSupport.Prover)` | a trie over `mapStore` | Map proofs from elsewhere (the runtime engine's caller supplies them) |
| `relays(List<Relay>)` | the backend alone | Keyed calls only: every attempt goes to each relay; any acceptance or unknown answer dominates rejections |
| `relayTimeout(Duration)` | 60 seconds | Keyed calls only: how long an attempt waits for each relay before its answer counts as unknown |
| `settlementSlots(long)` | 2 | Keyed calls only: slots past the last attempt's window before a series may end in a definite failure (at most 100,000) |
| `topUpAllowance(long lovelace)` | 10 ADA | Keyed calls only: the most an operation adds to an output to reach the ledger minimum |
| `pageLimits(long maxStartSlots, long maxValiditySlots)` | none | Keeps keyed calls' windows within a page's limits (the verifier's defaults are 60 and 900 slots) |
| `build()` | | The `StateRuntime` |

`StateRuntime.BuiltTx` is `record BuiltTx(String what, Transaction tx, boolean prepared)`: what the transaction is
for, the transaction (signed when submitted, unsigned when prepared), and which.

## ContractSpec

`public record ContractSpec<S>(String name, Class<?> validatorClass, Class<S> stateClass, long minAda,
int maxDatumBytes, long maxValidityMs, boolean stakeSelf, String scriptCborHex, List<Integer> mapFields)`. Each
generated client holds one as `SPEC`. Shorter constructors leave `stakeSelf` false and the rest null.
`static described(...)` builds the spec of a contract known only by its description and compiled script, with its
state as `PlutusData` (ADR-0015 D4). `layout()` locates the state's MerkleMaps.

## Compose

`public final class Compose`: several calls in one atomic transaction (ADR-0011 D1).

| Method | Returns | Description |
|---|---|---|
| `static of(StateRuntime runtime, Account payer)` | `Compose` | `payer` pays the fee |
| `add(Runnable call)` | `Compose` | Any client call: action, destroy, deploy, owned call |
| `allowSharedSigners()` | `Compose` | Lets one key's signature count for several calls (refused by default) |
| `submit()` | `String` | Builds, checks, submits and confirms; returns the hash |
| `prepare()` | `PreparedTx` | Builds for a wallet to sign; the payer and every caller must be `WalletAccount`s |
| `designate(String ref)` | `Compose` | For `prepare()` only: the wallet input (`txhash#index`) a page designated for a keyed call ([Keyed objects](#keyed-objects)) |

Refused before submitting: one UTxO spent by two calls; two calls minting under one policy; validity windows that do
not overlap; a key signing for more than one call (without `allowSharedSigners()`); a deposit into an instance whose
call in the transaction is not `@Receives`. Inside another composition, `submit()`/`prepare()` join the outer
transaction (`prepare()` cannot be nested).

## PreparedTx

`public final class PreparedTx`: a balanced transaction waiting for wallet signatures.

| Method | Returns | Description |
|---|---|---|
| `cbor()` | `String` | The unsigned transaction, hex CBOR, for CIP-30 `signTx(cbor, true)` |
| `txHash()` | `String` | |
| `requiredSigners()` | `List<String>` | Key hashes (hex) that must sign: the payer's and each caller's |
| `validTo()` | `long` | The last valid slot, or -1 if unbounded |
| `plan()` | `Map<String, Object>` | The portable plan of the transaction (`TxPlan`) |
| `transaction()` | `Transaction` | A copy, for inspection |

## Keyed objects

ADR-0016; on `main`, not in `0.1.0-pre1-rc2` (it comes with the next release). Guide:
[Keyed objects](/contracts/keyed-objects/).

| Class | Key members | Description |
|---|---|---|
| `KeyedList<S, R>` | `KeyedList(StateInstance<S>, KeyedType<R>)`, `type()`, `instance()`, `unit(byte[] key)`, `find(byte[] key)` (`Optional`), `get(byte[] key)`, `exists(byte[] key)`, `keys()`, `insert(Insert<R>)` | One keyed type's list in one instance. `find` and `get` validate the node; "not found" means the provider returned nothing. `keys()` walks from the head and reports a broken walk as an inconsistent snapshot. `insert` is refused on the JVM if the key is taken |
| `KeyedList.Entry` | `record Entry(byte[] key, boolean retired)`, `keyHex()` | One key of a walk |
| `KeyedList.Insert<R>` | record, filled in by generated clients | An insert: the method's name, caller, payment, and how to run the method and build its redeemer |
| `KeyedObject<S, R>` | `key()`, `keyHex()`, `unit()`, `list()`, `utxo()`, `value()`, `retired()`, `lovelace()`, `call(Call<R>)`, `remove(Call<R>)`, `retire(Call<R>)`, `RUNTIME_BURN` | One keyed object, live or retired. `remove` burns the token and relinks the predecessor; `retire` needs no neighbour |
| `KeyedType<R>` | record: `name()`, `headTag()`, `keyIndex()`, `maxKeyBytes()`, `signedKey()`, `cooldownMs()`, ...; `typeId()`, `keyId(byte[] instance, byte[] key)`, `keyOf(R)`, `MAX_ARGUMENT_BYTES` (4,096) | A keyed type's tags, key, bounds, cooldown and window (the generated `<T>_TYPE`) |
| `Relay` | `Outcome submit(byte[] cbor)`; `static of(BackendService)`, `static classify(Result)`; `Answer` (`ACCEPTED`, `REJECTED`, `UNKNOWN`), `Outcome` | Where a keyed operation's attempts are sent (`StateRuntime.Builder.relays`) |

Every keyed operation designates one ordinary (ADA-only, at least 5 ADA) UTxO of the payer and spends it in every
attempt, so at most one attempt can land. A composition with a keyed call does the same; `Compose.designate(ref)`
names the input a page chose before `prepare()`, which refuses a keyed call without one or composed with other calls.

| `POST /api/prepare` | `{ contract, kind, method, instance, object, args, pay: { lovelace, assets }, address }` | `{ cbor, txHash, validTo, signers, plan, instance?, object? }` |
